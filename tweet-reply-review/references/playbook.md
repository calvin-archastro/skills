# Reply playbook (evidence)

Source window: ~2 weeks of original posts from two technical accounts  
(Account A ~7k followers; Account B ~25k followers).  
Optimize for **replies**, not likes/views.

No person names or handles — only pattern shapes and anonymized metrics.

## Core law

Replies need an **answer-path**: disagree, self-slot, try a thing, or answer a real question.  
Heat without a path (hot take one-liner, diary QT) → views maybe, replies no.

### Account A counterexamples

| Result | Why it failed for replies |
| --- | --- |
| Stack one-liner "Why aren't you?" — 13k views, **2 replies** | Heat, no answer-path / no thread |
| Dogfood one-liner, emoji formula | No tension, no ask, no artifact |
| Version bump / long "feedback loops" essay | Ship or lecture without sharp pain+ask |
| QT mega-account as diary (laptop install notes) | No take, no question |

### Account A timing (secondary)

Top reply posts: weekday ~15:00–22:00 GMT; weekend late morning–afternoon.  
More important: online to farm replies 30–60m after post.

### Account A templates

**Pain → ship**
```
[Pain everyone feels].
[One metaphor / credit].
We built [thing]: [1-sentence mechanism].
Open source: [link]
Early — [honest limit]. What breaks for you?
```

**Confessional**
```
I REALLY hate [practice]. It's also the only thing that keeps me from becoming [worse].
[Short story].
[Present tension].
Anyone else fighting this?
```

**Contrarian thread**
```
1/ Everyone's on [default]. We're on [weird].
Not for clout — because [product constraint].
…
N/ Happy to go deeper on [A, B, C]. Ask.
```

| 45 | 36k | Debunk + prove me wrong | "$100k/mo token spend is mostly fake" |
| 32 | 39k | Gift / FAQ dump | "Nth time asked" → blog + dotfiles |
| 30 | 9k | Origin story | Tool hit 3k stars — built for an *experience*, not another harness |
| 24 | 14k | Self-own absurdity | Nested SSH roundtrip spaghetti |

### Account B engines (repeatable)

1. **Teach mechanism** — define terms (RLHF/RLVR), chain logic, invite correction/extension  
2. **Taxonomy** — 2–4 buckets; end with self-placement  
3. **Challenge** — show me / prove me wrong  
4. **Gift** — answer the FAQ once with full dump  
5. **Blueprint** — copyable routing/rules; people reply with their deltas  
6. **Culture spike** — shared impatience/emotion; low frequency  
7. **Reply presence** — caveats, links to prior essays, multi-day thread  

### Account B weaker for *discussion* replies

- Pure friend-boosts (huge likes, fewer arguments)  
- Thin "check this out" pointers  
- Product PSA without opinion  

### Account B voice notes

- Lowercase casual technical essay (notes, not PR)  
- Series continuity (later posts cite earlier definitions)  
- Alternate formats so the feed doesn't fatigue

## Post-ship reply-farm (both)

1. Be online 30–60m  
2. First replies: technical, specific, one question back  
3. Pre-write 2–3 angles (how it works, limits, when it doesn't help)  
4. Elevate good critiques into a follow-up post (caveat-style)  
5. Do not only post "thanks!" — dead end for secondary replies
